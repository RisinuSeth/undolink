Password-protected links, explained.

A password prompt adds a simple check before someone follows a shared redirect. It can be useful for limited sharing, but it is important to understand what the password does—and what it does not do.

What does password protection mean for a link?

A password-protected link asks a visitor to enter a password before continuing through the redirect. The person needs both the link and the correct password to pass that check.

With UndoLink, the password is an optional setting when you create a temporary link. A visitor is asked for the password before being sent to the destination.

Important: this protects the redirect step. It does not add a password to the destination website, encrypt the destination, or control what happens after the visitor reaches it.

How the password check fits into sharing

  1. Choose your destination. Use the page or resource you want the recipient to reach.
  2. Add a link password. Choose a password that is not easy to guess and that you do not reuse for an important account.
  3. Set an expiry if appropriate. A password and a time limit can work together: one checks the visitor, the other defines how long the redirect stays available.
  4. Share the link and password with the intended recipient. The visitor enters the password before the redirect continues.

If the link also has a scheduled start or click limit, those rules still matter. A password does not override the other settings.

When is a password-protected link useful?

Sharing a preview with a small group

You may want to add a basic check before sending a preview page to a client, collaborator, or reviewer. Make sure the destination itself is also appropriate for those people.

Temporary team resources

A password prompt can add friction against casual access when sharing a temporary resource with a known group. For company or school documents, use the document platform's own account permissions as the primary control.

Pairing access with an expiry

For a time-limited review, you can use a password together with an expiry. This gives the link both an access check and a defined period of availability.

Share the password carefully

The password only helps if it is not distributed alongside the link to everyone who might see it. For a little more separation, send the link in one message and the password through a different channel.

  • Share the password only with the intended recipients.
  • Avoid reusing a password from your email, social media, or other important accounts.
  • Do not put sensitive personal information in the password itself.
  • If you think the password has been shared too widely, stop using that link and create a new one with a different password.
Example: a client review

Send a review link by email and provide the password in a separate conversation. Set an expiry that covers the review period. Keep the original file or page restricted to the client and collaborators who need it.

Know the security limits

Password protection is an extra step, not a complete confidentiality system. Anyone who receives both the link and password may be able to open it. A recipient may also share the password with someone else.

  • It does not encrypt the destination website or files.
  • It does not prevent a recipient from copying or saving information after access.
  • It does not replace sign-in, permissions, or sharing controls on the destination platform.
  • It cannot make an already public destination private.

For sensitive documents, use a service that supports named-user access, revocation, and appropriate audit controls. Treat the UndoLink password as an additional gate, not the only security measure.
